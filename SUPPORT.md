# Support policy

Herdr World support is GitHub Discussions for questions and help, and GitHub
Issues for reproducible bugs, documentation defects, and focused feature
requests. Please include the World version, Foundation/bridge version, Herdr
version and terminal protocol, operating system, exact reproduction steps,
and redacted logs. Never include credentials, note or terminal content, or
private local paths.

Support is latest-stable and best effort. There is no service-level agreement,
guaranteed response time, or promise that Herdr, Herdr Web, or their
maintainers support Herdr World users. A bug in a component belongs in that
component's lane:

- Herdr runtime, plugin, public API, or terminal protocol: Herdr's issue and
  discussion process.
- Generic Herdr Web behavior: Herdr Web's current contribution and issue
  process.
- Foundation package, bridge packaging, or compatibility slice: the Foundation
  repository's issue/discussion lane.
- Office, World branding, downstream providers, release policy, and this
  product: the World repository's issue/discussion lane.

Security reports are private; follow `SECURITY.md` instead of opening an
Issue.
